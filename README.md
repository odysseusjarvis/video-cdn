# Autoelektrika E-Drive - Web Stranica

Premium web stranica za **Autoelektrika E-Drive** (@edrive.servis), servis za auto-elektroniku u Gradačcu, BiH.

## Tech Stack

- React + Vite
- Tailwind CSS v4
- Framer Motion
- React Router DOM
- Lucide React

## Pokretanje

```bash
npm install
npm run dev
```

## Stranice

- **Početna** (`/`) — Hero, pregled usluga, statistika, CTA
- **Usluge** (`/usluge`) — 8 detaljnih servisnih kartica
- **O Nama** (`/o-nama`) — Priča, ekspertiza, vrijednosti
- **Galerija** (`/galerija`) — Filtrirajuća galerija sa lightboxom
- **Kontakt** (`/kontakt`) — Forma, kontakt info, mapa

## Kontakt Podaci

Placeholder kontakt podaci se nalaze u `src/config/site.js` — zamijenite ih stvarnim podacima.
